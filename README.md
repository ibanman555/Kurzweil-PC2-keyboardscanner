This fork is a adaptation of Moura's keyboard scanner project specifically designed to work with the Kurzweil PC2 keybed. This includes full functionality of all 76 keys with velocity. It will also include sustain pedal, the pitch and mod wheels, and the two switches near those wheels for octave shift.

This project is designed for use with the Arduino Mega 2560, and as such includes the complete sketch to load into the Mega 2560, as well as a custom KiCad file to manufacture a Mega 2560 shield that will allow for plug & play setup with the existing keybed and wheel connectors, no cable cutting or soldering required. Additionally, the option to add a 1/4" TS plug to the shield for a sustain pedal.
