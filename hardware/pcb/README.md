# PC2 Mega 2560 Shield — PCB Manufacturing

This folder contains the manufacturing package for the custom **Arduino Mega 2560 shield used in the Kurzweil PC2 76-key MIDI-controller conversion**.

The board brings the original PC2 keybed ribbons, pitch/mod/pressure connector, SW4/SW5 octave buttons and LEDs, and a 1/4-inch sustain-pedal input onto one Mega 2560.

## Personal manufacturing

These PCB manufacturing files are provided so builders of this project can have the shield fabricated for **personal use**.

The ready-to-upload manufacturing archive is:

`PC2-Shield-Gerbers.zip`

Once generated by the repository workflow, that ZIP can be downloaded directly from this folder and submitted to a PCB manufacturer.

Before ordering, use the manufacturer's Gerber viewer to confirm board outline, copper, solder mask, silkscreen, plated holes, non-plated holes, and connector orientation.

## Files in the manufacturing package

The original supplied manufacturing archive contains:

- `PC2 Shield-F_Cu.gbr` — front copper
- `PC2 Shield-B_Cu.gbr` — back copper
- `PC2 Shield-F_Mask.gbr` — front solder mask
- `PC2 Shield-B_Mask.gbr` — back solder mask
- `PC2 Shield-F_Silkscreen.gbr` — front silkscreen
- `PC2 Shield-B_Silkscreen.gbr` — back silkscreen
- `PC2 Shield-Edge_Cuts.gbr` — board outline
- `PC2 Shield-PTH.drl` — plated drill file
- `PC2 Shield-NPTH.drl` — non-plated drill file
- `PC2 Shield-job.gbrjob` — Gerber job file

## Rebuilding the manufacturing ZIP

The original ZIP is stored losslessly in four Base64 text parts so GitHub can reconstruct the exact uploaded manufacturing archive.

From the repository root, run:

```bash
python3 hardware/pcb/build_manufacturing_zip.py
```

This creates:

```text
hardware/pcb/PC2-Shield-Gerbers.zip
```

The script verifies the resulting file against the original archive checksum:

```text
SHA256 bba3b698239ae15a7b6911c9d39496f48149648c18474a0976c9111cb7ca5255
```

## Automatic package generation

The GitHub Actions workflow **Package PCB manufacturing files** performs the same reconstruction and ZIP-integrity check automatically, then commits the ready-to-download `PC2-Shield-Gerbers.zip` into this folder.
